APPLY ON YOUR MAC

1. Unzip the downloaded archive in Downloads.
2. Locate the extracted renatus folder. It contains package.json and
   zachry-insurance-case-study.html.
3. If that folder is ~/Downloads/renatus, run:

rsync -av --exclude='.git/' --exclude='node_modules/' --exclude='.env' --exclude='.env.local' --exclude='dist/' ~/Downloads/renatus/ ~/Desktop/IdeaProjects/RENATUS/renatus/
cd ~/Desktop/IdeaProjects/RENATUS/renatus
npm run check
git diff --stat

Change the source or destination path if your folders are elsewhere. Check the
paths before running rsync. The command merges files without deleting files and
does not copy Git history or overwrite local environment files. It rebuilds dist
using your existing project and requires Node 22 or newer.

Review the changes with npm run dev. Preview /zachry-insurance-case-study,
/insights, and the homepage on desktop and mobile. Then commit and push using your usual Git
workflow to deploy through Netlify. Keep netlify/functions with the source project;
uploading only dist does not deploy the scanner function.
