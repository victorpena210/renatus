QUESTIONS / BEFORE WE START

Know what you’re buying.

What does custom software cost at Renatus?

Custom software projects typically begin at $20,000. A narrowly scoped internal tool can start at $12,500; business operations platforms start at $35,000. More complex multi-user or multi-tenant platforms are generally planned at $45,000–$75,000+. A written proposal establishes the actual price and deliverables.

What changes the final project price?

The number of workflows, user roles, business rules, integrations, reporting needs and data migrations affects the work. We also define testing, deployment, documentation and handover. New requirements receive an agreed scope and price before implementation.

Is discovery included in the build price?

Software discovery and architecture is a separate $2,500–$5,000 engagement when needed. Its fee, deliverables and any credit toward implementation are agreed in writing before work begins. An initial project conversation is free.

How are payments and ownership handled?

The proposal sets milestones, acceptance criteria, payment dates, source-code ownership, third-party licenses and handover requirements. We agree on those details before development. Website subscription terms are listed below.

What is the difference between Website Care and Software Care?

Website Care is $299/month for a supported business website. Software Care starts at $750/month for an application with database, user-access and operational maintenance needs. Priority software support with a defined development allocation is planned at $1,500–$3,000+/month.
